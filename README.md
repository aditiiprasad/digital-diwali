# Digital Diwali ✨🪔

![Digital Diwali — pataka gali at night](public/assests/images/image.png)

Made **just for fun**. Drag patakas from the shop → road → tap to light. Fuljhadi = hold and doodle sparks. Rain, ambience, fairy lights, **Gali Radio**.

**IRL:** safe, happy, **eco-friendly Diwali** — real smoke not required; this site is the loud part.

**[Play on Vercel](https://digital-diwali.vercel.app)** · local: `npm install && npm run dev` → **Enter the Gali**

**Radio:** Bollywood bangers in [`src/data/playlist.ts`](src/data/playlist.ts). My taste in music? Immaculate. **Do check the playlist.**
